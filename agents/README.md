# Agents

Planned roles:

- **Commander / Planner** — turns a request into an execution plan.
- **Research Agent** — gathers repository, documentation, and runtime evidence.
- **Code Agent** — proposes or applies code changes through approved tools.
- **Testing Agent** — executes validation and analyzes failures.
- **Reviewer Agent** — checks correctness, evidence, safety, and completeness.

Agents should remain focused on roles while shared state, policy, and tool access stay in the core runtime.
